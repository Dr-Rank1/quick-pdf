| `feature_graphic_1024x500.png` | 1024×500 PNG, ≤15 MB | Feature graphic |
| `app-release-1.1.0+7.aab` | Android App Bundle | Upload to Play Console (sign before release if needed) |
| `play_store_screenshots/` | 1080×1920 PNGs | Phone screenshots (7) |
